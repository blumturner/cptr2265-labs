Student Grade Tracker - SRS

Introduction

The Student Grade Tracker is a system designed to help students manage their courses, assignments, and grades in one place. 
The purpose of the system is to make it easier for students to keep track of their grades and understand their progress in 
each course. The system will allow users to add and remove courses, add and manage assignments, enter and edit grades, calculate 
course averages, view course information, and save their data. The system is intended to provide a simple and easy way for
students to organize their academic information.


Functional Requirements

FR01. The system shall allow the user to add a course.
FR02. The system shall allow the user to remove a course.
FR03. The system shall allow the user to add an assignment to a course.
FR04. The system shall allow the user to enter a grade for an assignment.
FR05. The system shall allow the user to edit an existing grade.
FR06. The system shall allow the user to delete an assignment.
FR07. The system shall calculate the average grade for a course.
FR08. The system shall display a summary of a selected course.
FR09. The system shall save the user's course and assignment data.
FR10. The system shall allow the user to view a list of their courses.
FR11. The system shall display assignment grades associated with each course.
FR12. The system shall notify the user when required information is missing or invalid.



Non-functional Requirements

NFR01. The system shall update course averages within two seconds after a grade is entered or changed.
BFR02. The system shall provide an interface that allows a new user to enter and view grades without needing additional instructions.
NFR03. The system shall correctly save course, assignment, and grade information when the user saves their data.
NFR04. The system shall prevent unauthorized users from accessing stored student grade information.
NFR05. The system shall use separate modules for course management, assignment management, grade calculations, and data storage 
so that individual parts can be updated without changing the entire system.
