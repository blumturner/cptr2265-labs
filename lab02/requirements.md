Student Grade Tracker

Functional Requirements:
- Add course
- Remove course
- Add assignments 
- Enter Grade
- Edit Grade
- Delete Assignments
- Calculate Course Average
- Display Course Summary
- Save User Data

Non-functional Requirements:
- Usability, the system should have a easy to understand interface so that a new user can enter and view grades without instructions.
- Performance, the system should calculate and display updated grades within a couple seconds after the user enters or changes a grade.
- Reliability, the system should correctly save user data
