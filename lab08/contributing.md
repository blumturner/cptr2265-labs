Branching Policy

This repository uses GitHub Flow for development. The main branch contains completed work and is protected from direct changes.

New work should be done on a separate feature branch created from main. Feature branches should have names that describe the work being done.

Changes should be committed to the feature branch and pushed to GitHub. A Pull Request must then be created to merge the changes into main.

Pull Requests require at least one approval from another contributor before they can be merged. Changes should not be pushed directly to main.

After the Pull Request is approved and merged, the feature branch can be deleted.
