# Sprint 1 Planning

## Sprint Goal

The goal of Sprint 1 is to develop the basic functionality of the Student Grade Tracker so that a student can create a course, add assignments, enter grades, calculate a course average, and save their information. This sprint focuses on creating a usable foundation for the rest of the system.

## Selected User Stories

The five stories selected for Sprint 1 are Add a Course, Add an Assignment, Enter a Grade, Calculate Course Average, and Save User Data. These were chosen because they represent the main functions needed for the system to be useful. A student must first be able to create a course before adding assignments and grades to it. Once grades are entered, the system needs to calculate the course average and save the information so it is not lost when the application closes.

These stories were prioritized because they form a connected workflow and provide the core functionality of the application. Completing them will allow the team to create an initial working version of the Grade Tracker. Features such as displaying a course summary, editing grades, deleting assignments, and removing courses can be completed in later sprints after the basic system is working.
